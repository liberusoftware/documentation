## 1. Purpose and ownership

This optional API presentation package exposes approved HTTP operations for the Payment Paddle Adapter domain module. It presents exactly one independent module, delegates all authoritative behavior to that module's public actions/queries/policies (`liberusoftware/payment-contracts (PaymentGatewayAdapterContract, PaymentIntentServiceContract, PaymentCaptureAndRefundContract, SavedPaymentMethodVaultContract, MerchantWebhookVerifierContract, DisputeAndChargebackHandlerContract, PayoutAndSettlementReconcilerContract)`), and contains no other module's API logic.

The domain capability includes:

- Paddle Billing transactions and Merchant-of-Record checkout
- Paddle adjustments for full/partial refunds and credits
- Customer saved payment methods and subscription bridge
- Paddle-Signature ts/h1 HMAC webhook verification
- Tax, Merchant-of-Record fee, and payout reconciliation

Installation does not expose every capability automatically. The host application selects this package, API version, audiences, route groups, and operations in its API manifest.

## 2. Contract design

- Publish an OpenAPI 3.1 fragment with stable operation IDs, schemas, examples, scopes, errors, pagination, rate limits, idempotency, and deprecation metadata.
- Choose the route namespace through the host's reviewed API contract (`/api/v1/payment-paddle`).
- Represent resources through explicit API DTOs/resources rather than automatic Eloquent serialization.
- Use lowercase kebab-case paths, snake_case JSON fields, opaque identifiers, ISO 8601 timestamps, explicit minor-unit money objects, and RFC 9457 Problem Details errors.
- Compatible additions remain within the major version; removals or semantic breaks require a new major version or approved migration path.
