# Technology wayfinder specifications

Each non-Filament project host has a GitHub wayfinder issue. These pages are the durable, technology-specific implementation method and technical specification those issues follow. Product capability checklists remain in the issues; framework depth lives in standards and presentation runbooks linked from each page.
