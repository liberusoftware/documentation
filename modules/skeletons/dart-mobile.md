# Dart · Mobile capability repositories

[All presentation catalogs](README.md) · [Project application catalog](../../projects/REPOSITORIES.md) · [Layer initialization guide](../../guides/presentation/DART.md)

Separate Dart mobile application with a Flutter host for iOS and Android. Laravel remains authoritative for domain rules and tenant authorization. These are independent Dart/pub packages. Repository names and registry identities are separate; an existing implementation keeps its actual manifest identity. New skeletons are prerelease foundations, not implemented feature parity.
