# Laravel · Inertia · React capability repositories

[All presentation catalogs](README.md) · [Project application catalog](../../projects/REPOSITORIES.md) · [Layer initialization guide](../../guides/presentation/INERTIA.md)

Repository names and registry identities are separate; an existing implementation keeps its actual manifest identity. New skeletons are prerelease foundations, not implemented feature parity.
