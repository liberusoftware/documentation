# Vite technology reference

Vite is the asset and development tool used by Laravel, React/Inertia, Vue/Inertia, Nuxt integrations, and theme adapters.

## Common commands

```bash
npm run dev
npm run build
npm run preview
```

Keep environment variables intentionally prefixed and public only when safe for browser exposure. Use aliases that match TypeScript configuration, code-split optional features, inspect production output, and keep Vite plugins minimal and maintained.

Official references: [Vite guide](https://vite.dev/guide/), [configuration](https://vite.dev/config/), [build guide](https://vite.dev/guide/build), [Vite plugins](https://vite.dev/guide/using-plugins), and [Vite GitHub](https://github.com/vitejs/vite). Related local guides: [JavaScript](JAVASCRIPT.md), [TypeScript](TYPESCRIPT.md), and [theme architecture](../standards/THEMES.md).
